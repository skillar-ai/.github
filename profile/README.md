### The Mission

At **Skillar.ai**, we bridge the gap between employee competencies and organizational requirements. Our platform automates workforce compliance, maps sector-specific roles, and generates adaptive learning roadmaps to close capability gaps instantly.

We replace manual spreadsheets with continuous, scheduled assessments and track upskilling ROI directly from the department level down to a single person.

---

### Core Capabilities

| Module | Description |
| :--- | :--- |
| **Skill Intelligence** | Mapping exactly what skills each role requires versus what employees currently possess. |
| **Workforce Compliance** | Automating continuous, scheduled assessments to replace manual compliance tracking. |
| **Adaptive Learning** | Creating personalized revision and training paths derived from objective performance data. |
| **Analytics and Reporting** | Tracking upskilling ROI from the department level down to individual contributors. |

### Engineering Standards

We believe in maintaining rigorous code quality. Whether you are a core team member or an outside collaborator, please adhere to the following standards:

1. **Branch Protection:** All core code is under strict branch protection. Direct commits to main branches are disabled.
2. **Pull Requests:** All changes must be submitted via Pull Request with required CI checks passing and at least one approving review.
3. **Issue Tracking:** Report bugs or submit feature requests using the standardized Issue Templates provided in each repository.
4. **Documentation:** Public APIs and core modules must be documented prior to merge.
